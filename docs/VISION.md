# Vision & Roadmap

Track new phases, features, and improvements to existing behavior here. Bugs go in [DEFECTS.md](./DEFECTS.md), not here.

## How to use

1. Add big-picture ideas to **Vision** and group concrete work into **Phases**.
2. Add each feature or update as an item (`FEAT-NNN` for new, `UPD-NNN` for changes to existing behavior).
3. Update status as work progresses.

**Type:** `Feature` (new) · `Update` (change to existing)
**Priority:** `P0` (must) · `P1` (should) · `P2` (nice to have)
**Status:** `Idea` · `Planned` · `In Progress` · `Done` · `Dropped`
